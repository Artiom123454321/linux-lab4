# Лабораторная работа №4 — анализ успеваемости и посещаемости (Linux / Bash)

## Исходные данные

В `data/` находятся исходные файлы из `labfiles-3-26.zip`: списки студентов в `students/groups/`, файлы `<ГРУППА>-attendance` для двух дисциплин, и `tests/TEST-1` ... `TEST-4`.

Дисциплины: `Цирковое_Дело` (1) и `Пересдачеведение` (2).

Одна строка посещаемости: `ФИО 010110...`, где позиция в последовательности — номер занятия (от 1), `1` означает посещение. Одна строка теста: `группа;ФИО;дата;правильные_ответы;оценка`.

## Запуск

Требуется Linux, Bash 4+, стандартные `grep` и `sort`. Python не нужен для запуска. Откройте терминал в каталоге решения:

```bash
chmod +x main.sh test.sh
./main.sh
```

Возможен запуск без меню:

```bash
./main.sh worst A-06-21
./main.sh failed A-06-21 1 1
./main.sh rank A-06-21
./main.sh average A-06-21 A-09-21
./test.sh
```

Номер группы задаётся полностью, включая год (`A-06-21`), поскольку в архиве есть несколько выпусков одной группы. Для команды `failed` сначала задаётся тест 1–4, затем предмет 1–2.

## Функциональность и правила расчёта

1. **Худшая посещаемость**: среди студентов указанной группы находится минимум **по сумме посещённых занятий обеих дисциплин**. Для найденного студента выводятся количество и номера посещённых занятий отдельно по каждому предмету. При ничьей выводятся все студенты с минимальным количеством.
2. **Не сдали тест**: студенты из списка группы, у которых в выбранном предмете/тесте нет ни одной попытки с оценкой `>=3`; отсутствие попыток также означает «не сдал».
3. **Рейтинг успеваемости**: для каждого из восьми тестов (два предмета × четыре теста) берётся **максимальная успешная оценка** (`>=3`). Не сданный тест даёт `0`. Студенты сортируются по убыванию суммы из 40, при равенстве — по ФИО. Отображается средний балл по восьми тестам и число сданных тестов.
4. **Средняя посещаемость**: отношение количества всех посещённых занятий к общему количеству занятий в каждой запрошенной группе по двум дисциплинам, выраженное в процентах до двух знаков после запятой. Это взвешенное среднее по всем отметкам группы.

**Предположения, которые можно уточнить у преподавателя:** понятие «худшая посещаемость» может определяться по каждой дисциплине отдельно, а «успеваемость» — по среднему только сданных тестов вместо восьми. Здесь критерии определены однозначно в пользу совокупных показателей. При равном числе посещённых занятий для студентов предполагается одинаковое общее число занятий, как в исходных файлах.

## Структура

- `main.sh` — меню и консольный интерфейс;
- `functions.sh` — реализация четырёх функций и проверка аргументов;
- `test.sh` — автоматические проверки;
- `testing_report.md` — отчёт о тестировании;
- `development_log.md` — этапы разработки;
- `data/` — неизменённая копия архивных данных.

Скрипты не используют `awk`, не изменяют данные преподавателя, не требуют прав администратора и формируют результаты только в терминале.
