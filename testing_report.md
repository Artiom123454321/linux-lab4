# Отчёт о тестировании ЛР №4 — версия с улучшенным вводом и рейтингом

## Среда

Linux / Ubuntu (в том числе WSL), Bash 4.3+, стандартные `grep`, `sort`. Данные — неизменённая файловая система преподавателя из ЛР №3.

## Автоматическое тестирование

Запуск: `bash test.sh`.

Проверяются:

1. Новый формат вывода посещаемости и номера посещённых занятий.
2. Все формы записи групп: латинская A/a, кириллическая А/а, префикс Ae/Аэ, только цифры и цифры через дефис.
3. Список доступных групп.
4. Учёт успешных оценок с символами `+/-`.
5. Разница между первой и второй попытками, а также проверка всех попыток.
6. Наличие реально несдавших тест.
7. Новый рейтинг: **средняя по всем попыткам** и количество попыток, один и два предмета, сортировка по убыванию.
8. Средняя посещаемость для **выбранного предмета** или обоих, конкретных групп, года группы и номера за все годы.
9. Ошибки ввода: отсутствующая группа, предмет/тест/попытка/режим средней посещаемости.
10. Интерактивное меню: мгновенная валидация, повтор ввода, отмена на разных этапах, смешанная строка `а1п` как неверная команда.
11. Строгое чтение кириллических символов с Backspace через псевдотерминал.

Для демонстрации:

```bash
bash main.sh failed 1 1 A-09-23 0
bash main.sh failed 1 1 A-09-23 1
bash main.sh failed 1 1 A-09-23 2
bash main.sh rank A-09-23 1
bash main.sh average --subject 1 A-06-21
bash main.sh average --subject 2 --year 2023
bash main.sh average --year 2023
bash main.sh average --number 06
bash test.sh
```

## Производительность

До оптимизации рейтинг открывал тестовые файлы многократно — для каждой пары (студент, тест). Теперь скрипт читает каждый нужный файл только один раз и накапливает оценки в ассоциативных массивах. При локальном замере рейтинга группы `A-06-23` старый скрипт занимал около **1.04 с**, обновлённый — **0.09 с**. Время зависит от компьютера и расположения проекта.

## Ограничения

- Номер N-й попытки определяется хронологически по датам; одинаковые даты разрешаются порядком строк.
- `3-`, `3+`, `4--` и `5++` считаются сданными по основной цифре, поскольку иной порядок интерпретации знаков заказчиком не установлен.
- `23` в режиме посещаемости — суффикс имени группы, а не календарный год тестирования.
- Для сдачи в GitHub следует повторно сделать скриншоты **обновлённой** версии программы.

## Ограничения и правила

- Средняя оценка — обычная арифметическая **по всем попыткам** выбранного предмета (все четыре теста); более частые пересдачи имеют больший вес, поскольку считаются отдельными попытками.
- В оценке основная цифра `2`–`5` используется без поправок от знаков `+` и `-`, даже если их несколько.
- При отмене ввода нажмите `q`/`назад` + Enter; команда прерывается без изменения файлов данных.
- Настройка `stty iutf8` эффективна в Linux-терминалах, поддерживающих этот флаг. Если терминал не поддерживает флаг, остальные функции продолжают работать.
- Новые скриншоты следует сделать после обновления проекта в GitHub.
