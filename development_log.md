# Журнал разработки лабораторной работы №4

## Этап 1. Анализ файловой системы из ЛР №3

Выделены списки групп в `data/students/groups/`, два предмета с файлами посещаемости `<группа>-attendance` и четырьмя тестами `tests/TEST-1` ... `TEST-4`. Все источники используются только для чтения.

## Этап 2. Первая версия

Созданы `main.sh`, `functions.sh`, `test.sh`. Реализованы четыре функции: минимальная посещаемость, несдавшие тест, рейтинг по восьми тестам и посещаемость заданных групп. Подготовлены README и отчёт о тестировании.

## Этап 3. Уточнённые требования заказчика

- Стандартизирован вывод минимальной посещаемости: группа, ФИО, минимум, предметы и номера занятий.
- В функции несдавших изменён порядок ввода на предмет → тест → группа → номер попытки.
- Учтены знаки `+/-` после базовой оценки, включая повторные (`3++`, `4--`).
- При ограничении попыток данные сортируются по дате сдачи отдельно по каждому студенту.
- Рейтинг разделён по первому, второму или обоим предметам.
- Переработан алгоритм рейтинга: каждый `TEST-N` читается один раз за расчёт.
- В среднюю посещаемость добавлены режимы по году группы и по номеру независимо от года, с агрегированным итогом.
- Добавлена команда перечисления групп и нормализация латинских/кириллических префиксов, регистра и сокращённой цифровой записи.
- Добавлены проверки новых форматов данных и некорректных параметров.

## Этап 4. Проверка

Выполнены автоматические сценарии `bash test.sh`, проверка основных функций на группах `A-06-21`, `A-06-23`, `A-09-23` и `Ae-21-23`, включая оценку `4+` у `NaimanAM`. Сопоставлены результаты рейтинга с предыдущей версией; расхождение объясняется тем, что прежняя версия ошибочно игнорировала оценки с символами `+`/`-`.

**Примечание:** изображения старой версии меню после обновления надо заменить на актуальные скриншоты.

## Этап 5. Расширенная сверка

Независимый алгоритм сопоставил 840 результатов для всех 30 групп с исходными файлами (в том числе N=0,1,2 попытки и 1/2/оба предмета), расхождений нет. Исправлен пограничный случай неуспешного кода возврата при последней обработанной записи.
