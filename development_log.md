# Журнал разработки

1. Проанализирован предоставленный архив `labfiles-3-26 (1).zip`, определены две дисциплины, файлы групп, посещаемости и тестов.
2. Согласована интерпретация форматов: битовая строка для посещаемости, CSV с `;` для тестов, группа с указанием года.
3. Реализована обработка строки посещаемости и поиск минимального числа посещений по двум предметам.
4. Реализован поиск студентов без успешной попытки теста; успешной считается оценка 3, 4 или 5.
5. Реализован рейтинг по сумме максимальных успешных оценок за восемь тестов.
6. Реализован расчёт доли посещений по выбранным группам.
7. Добавлены меню, параметры командной строки, сообщения о неверных аргументах и автоматические тесты.
8. Результаты тестирования записаны в `testing_report.md`.

Скрипты работают с копией исходного архива и не изменяют файлы преподавателя.
